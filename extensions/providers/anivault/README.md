# AniVault

On-device resolver for [anivault.tv](https://anivault.tv/).

When Hoshika answers, the phone asks anivault.co for every server button the site shows. When that catalog id hangs, the same origin scrapers that already ship on this phone fill those buttons by title:

- AnimeHeaven (sub)
- Anikoto → Hd-1 / Vidstream-2
- Reanime → Hd-2
- Aniwaves → Vidplay / BYFMS
- Anizone → Japanese / English

Each file keeps AniVault's label and lead key so the next episode warms from the server that just played. Their private scraper key stays on their server. Hindi / DesiDub still need the remote id.
