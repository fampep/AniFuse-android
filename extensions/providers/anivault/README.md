# AniVault

On-device resolver for [anivault.tv](https://anivault.tv/).

Sub playback starts from AniVault's AnimeHeaven file, resolved on the phone by title, because the Hoshika id lookup often never answers. Their other servers are still requested when that id is known. The next episode is warmed from the server that just played, alone. The private scraper key stays on their server.
