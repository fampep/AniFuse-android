## ⚠️ WARNING

- This build installs over AniKitty 1.2.10 and the 1.2.11-dev builds. It is signed with the same key as those releases. Your library, watch progress, and AniList login stay on the device.
- Nothing is reset and there is no settings migration.
- If Android says the package conflicts, the installed copy was signed with a different key (a debug or unofficial build). Uninstalling that copy deletes its local library. The AniList account itself is unchanged.

## 💥 Breaking changes

None.

## 🔧 Fixes

### Cast
- **Casting works in the release APK again.** The release build's code shrinker was stripping the Cast entry point (`AniKittyCastOptionsProvider`), which is looked up by class name from the manifest, so Cast could never start and the button only said "Cast didn't start". Debug builds hid the bug because they are not shrunk. The provider, playback service, and relay are now kept, so the Cast button, receiver handoff, and TV playback work in shipped APKs.

## ✨ What's new

### Playback
- Captions no longer hold up the video. The subtitle listing is cached (memory + disk), prefetched while the stream is being resolved, and attached late without pausing or re-buffering the episode. If the subtitle host is slow or down, playback still starts.
- **Auto-skip intros and outros** is a new player setting. Previously only recaps auto-skipped; now intros, outros, and previews can skip too, once their marker is reached.
- A first-run gesture hint explains double-tap seek, edge-drag brightness/volume, and long-press 2× playback.

### Subtitles
- The caption menu is now one **"Subtitles & style"** sheet instead of six separate pages: the track list on top, then a live preview with size and timing sliders, colour, edge, background, bold/italic, and reset-to-default.
- The current episode's cell in the player's episode grid shows its watch progress.

### Sources
- Failover now gives each provider at most 30 seconds, so one slow or dead source no longer stalls the others.

### Home
- A focused default home instead of a wall of rows: hero, latest episodes, continue watching, top 10, this season, and for you. The other rows (top airing, upcoming, plan to watch, top rated, because you watched, network, collection, genres) stay one tap away in Settings → Home rows. A home you have already arranged is left untouched.
- The hero page indicator now animates and follows the system animation setting.

### Title page
- Seasons are inline pills, so switching season is one tap instead of opening a list first.
- The backdrop gallery and background details are folded into a **"More info"** toggle, keeping the play → episodes path short.

### Motion and accessibility
- Animations across the app honour the system "remove animations" setting and settle instantly when it is on.
