## ⚠️ WARNING

- This build installs over AniFuse / AniKitty **1.2.11** and every **1.2.12bN** (and older `-dev.N`) build. It is signed with the same key as those releases. Your library, watch progress, and AniList login stay on the device.
- Nothing is reset and there is no settings migration.
- If Android says the package conflicts, the installed copy was signed with a different key (a debug or unofficial build). Uninstalling that copy deletes its local library. The AniList account itself is unchanged.

## 💥 Breaking changes

None for day-to-day watching. The product name on GitHub is **AniFuse**; the package stays `site.anikitty.app` so existing installs update in place.

## ✨ What's new

### Player
- Phone theater is **Plex-style AniFuse glass**: Previous · −10 · Play/Pause · +10 · Next, with a floating dock for Episodes / Sources / Quality / Subs / Speed.
- Scrubber shows **elapsed / −remaining**, SeekPreview stills + chapter chips, and intro/credits bands with marker haptics.
- Horizontal drag seeks through the same scrub path as the timeline (preview stays in sync). Brightness and volume stick to the **18% edges**.
- Double-tap ±10s flashes the seek HUD without revealing full chrome.
- Skip Intro / Outro is a **glass chip** cleared above the dock.
- Sticky Subs / Size / Color sheets **scroll** again — theater volume/brightness no longer steals the list drag.
- Episode sheet: now-playing prev/next discs, stills-first rail, jump + ranges + grid (enabled skip glyphs invert to black on white glass).

### Playback engine
- Adaptive bitrate soft-cap respects **Race-dock RTT** after a CDN swap; climb / soft-release stays zero-jank.
- Faster race when a host dies, colder stalls, progressive offline shadow arm/leave, and HLS segment retarget without restarting the episode.
- Downloads run in one lane that yields to playback.
- Media session holds across episode changes; next-episode captions and resolve warm in the background.

### Cast
- Live playhead commit on handoff, quiet phone while the TV owns audio, late resume / caption attach after failover, and safer keep-audio restore.

### Sources & extensions
- Glass **Race dock** with live HEAD RTT (replace stamps), preferred-CDN probe coalesce, and healthy-only probe waves.
- Bundled / store providers across the 1.2.12 line include **2Dhive**, **ani.pm** (Player API), **0neko**, **AniRex**, **AnimeHeaven**, AniWaves.tv multi-server, and related store glass — plus AniVault play/source fixes earlier in the line.
- AnimeHeaven no longer plays the watch-on-site promo instead of the episode.

### AniList & sync
- Batched / interactive MediaList pulls; background pace for shelf sync so Home GraphQL stays snappy.
- File-backed resolver caches and a faster AniList cold start.

### Glass UI
- Monochrome stage shell, parallax home slider, translucent store / shell / player chrome.
- Floating glass dock remains the thumb home for navigation.

### Releases
- Dev and stable version names follow the **uBlock Origin** form (`1.2.12bN` → stable `1.2.12`).
- Every GitHub release body now opens with the same README **WARNING** disclaimer as the project homepage.
