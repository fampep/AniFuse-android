## ⚠️ WARNING

- This build installs over AniKitty 1.2.9 and the 1.2.10-dev builds. It is signed with the same key as those releases. Your library, watch progress, and AniList login stay on the device.
- Nothing is reset. There is no settings migration.
- Saving an episode asks for notification permission on Android 13 and newer. The save runs as a foreground data-sync service until it finishes.
- If Android says the package conflicts, the installed copy was signed with a different key (a debug or unofficial build). Uninstalling that copy deletes its local library. The AniList account itself is unchanged.

## 💥 Breaking changes

None.

## ✨ What's new

### Playback
- Save an episode for offline playback. Cancel a queued or running save, including from the notification, and clear a failed one. An HLS save keeps one rendition.
- A rewind is kept. Opening a title does not mark it watched, and a finished episode marks at the credits or the last 90 seconds.
- Import a watch-progress backup without rolling back a newer save. A failed AniList push retries, and an unwatch does not push the old frontier again.
- Leave the player and local playback continues in a picture-in-picture window. The episode list opens as a sheet.

### Cast
- Join a TV that is already playing. The phone stays quiet while the TV has the episode, and a failed cast returns playback to the phone.
- Volume, speed, subtitles, and skip controls stay on the phone. The next episode can start from the TV.

### Sources
- ani.nz, gogoanime.by, and anizone are bundled on-device sources. Intro and credits come from the stream when it has them.

### Home and library
- Home shows a banner when a newer sideload build is ready.
- A search with no matches shows the mascot. Titles, the dock, and episode cards are spoken once.

### Schedule
- A schedule row says the title once.
